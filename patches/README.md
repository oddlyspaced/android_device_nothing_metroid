# Required source patches

Maintainer candidates use topic commits outside this device repository. Until
the corresponding maintained forks exist, sync the immutable pre-patch
revisions recorded in `series.conf`, then apply and verify the complete series:

```bash
device/nothing/metroid/patches/apply-series.sh "$PWD"
```

The script refuses dirty repositories and wrong starting revisions. After each
project is patched, it verifies the resulting Git tree against `series.conf`.
Commit IDs created by `git am` may vary with committer metadata; the result tree
is the reproducibility contract.

## Base: Evolution X, not LineageOS 23.0

**This series is rebased onto Evolution X (`bka` / `lineage-23.2`).** It no
longer applies to the LineageOS 23.0 tree it was originally written against.
The pre-patch revisions in `series.conf` are the Evolution X manifest revisions
as of 2026-09-07:

- Evolution X projects at `evo/bka`
- LineageOS-hosted projects at `github/lineage-23.2`
- Qualcomm CAF projects at `github/lineage-23.2-caf-sm8750`
- `vendor/apn` at `github/main`

40 patches across 25 projects. Every one was replayed onto its recorded base and
verified to reproduce the recorded result tree.

Patch filenames and ordering are generated by `git format-patch`, so they follow
the commit subjects rather than the previous hand-maintained names. Apply the
whole series in glob order; do not cherry-pick. `Aperture` in particular fails a
standalone check on its camera-topology patch but applies cleanly in series
order.

### Carried build fixes for the 23.2 base

Two patches exist only to make the 23.2 tree build and have no LineageOS 23.0
counterpart:

| Patch | Why |
|---|---|
| `thermal` | The stock `android.hardware.thermal-service.qti` blob and this source HAL declare the same module name. The blob is tagged `MODULE_SUFFIX=.stock`, and this guards the source module behind `soong_config_variable("metroid", "stock_thermal")` so only one is built. |
| `display_hal` 0002 | `libgrallocutils` prints `uint64_t`/`int64_t` with `%lu`/`%ld`. Correct on arm64, wrong on arm32, so `-Werror,-Wformat` fails the 32-bit variant. metroid is `core_64_bit_only`, so `-Wno-format` is scoped to arch `arm` only. |

### Dropped: already upstream

`Fix MediaCodec error getting media_quality service` (AOSP, Bug 413228432) is
present in the Evolution X base byte-identical to its post-patch state. It has
been removed from the series. Do not re-add it.

## What the series covers

The framework patches carry the UDFPS coordinate override, two `system_server`
boot-safety fixes, and the metroid AudioFX keepalive binding. The AudioFX series
exports only a dedicated inert keepalive while its DSP service remains private;
the Settings series carries dependency-closed face-guidance fallback. The
recovery patch raises minui's input
device capacity so the PMIC power and volume-down keys are registered after
the phone's squeeze-sensor input nodes. The Soong patch restores the platform
security-patch property in the boot/init_boot ramdisk build properties.

The series includes every required framework, app, HAL, build, and recovery
patch. A candidate must not rely on an unlisted local commit. Do not apply it to
the recorded post-patch commits.

The vendor tree is proprietary and must not be published. Populate it from your
own stock dump with `extract-files.py`. Private extraction revisions remain in
the maintainer workspace and are not part of the public source lock.
